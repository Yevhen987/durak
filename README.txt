ДУРАК — установка на телефон (без Google Play)

В пакете: игра (index.html), иконки, manifest.webmanifest, sw.js (работа без интернета).
Онлайн-режим на 2–4 игроков работает через Firebase (кнопка 🌐). Можно играть и против бота.

ВАРИАНТ 1 (самый простой, без APK)
1. На GitHub создайте репозиторий (любое имя, например durak) и загрузите в него все файлы из этой папки.
2. Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
   Через 1-2 минуты игра откроется по адресу https://ВАШ_ЛОГИН.github.io/durak/
3. Откройте этот адрес в Chrome на телефоне -> меню (три точки) -> «Установить приложение» / «Добавить на главный экран».
   Появится иконка, игра будет открываться на весь экран.

ВАРИАНТ 2 (настоящий APK-файл, например чтобы отправить друзьям)
1. Сделайте шаги 1-2 из варианта 1.
2. Откройте pwabuilder.com, вставьте адрес игры, нажмите Start -> Package for stores -> Android.
   Выберите подписанный APK (Signed), скачайте архив.
   Сохраните файл ключа и пароли: без них APK нельзя будет обновить.
3. Скопируйте .apk на телефон и установите (разрешите установку из неизвестных источников).
   Шаг с assetlinks.json можно пропустить: тогда сверху будет видна адресная строка.

Когда обновляете игру, в sw.js меняйте версию durak-v2 на durak-v3 и т.д.
